Thought about

The small things that decide whether you keep it installed or turn it off on day two.

👀 Only when you're there

A note held back while you're at lunch isn't dropped — it waits and lands once you're back at the keyboard.

🎲 Never twice in a row

Timing is random inside your hours, and the last several dozen notes are remembered so nothing echoes.

🤖 Agent notifications

A note when Cursor, Claude Code or Codex finishes or needs you. One command wires it up.

🎨 Your own icon

Any emoji or image becomes the app icon, and each note carries its own badge on the right.

🪟 Settings window

A real window for frequency, hours and themes, if a config file isn't your idea of a good time.

🔒 Stays on your Mac

No account, no telemetry, no network at all unless you go and ask for the optional AI writer.

Runs on plain commands

Everything the window does, the terminal does too.

# the questionnaire, any time
stickynote setup

# mix two packs, nudge yourself now, take a break
stickynote packs funny,zen
stickynote now
stickynote pause 3h

# a note when your coding agent finishes
stickynote hooks install

Questions

Why a terminal command instead of a download button?

Because the download button would be worse, and this is the honest version of why.

Apple charges $99 a year to sign an app so macOS trusts it. Without that signature, a downloaded app doesn't just show a warning — on recent macOS it's blocked outright, and getting past it means opening System Settings, hunting for a security panel, and typing an admin password. That's a worse first five minutes than pasting one line.

So Sticky Note skips downloads entirely. The install command fetches the source and builds the app on your machine, which macOS trusts natively. One line, no warnings, nothing to click past.

Is it safe to pipe a script into bash?

Reasonable instinct. The script is short and readable — read it first if you like. It clones the repo, links one command onto your path, and runs the setup questions. Nothing needs sudo.

Does it send my data anywhere?

No. There's no account, no analytics, and no network access at all in normal use. Your settings live in a folder in your home directory and never leave it.

The one exception is opt-in and obvious: if you connect your own AI key to have it write new notes, that talks to whichever provider you chose. It's off until you set it up.

Will it get annoying?

You choose the rhythm during setup, from a handful a day to roughly one an hour, and you can change it whenever. Notes only arrive inside the hours you pick, only when you're actually at the machine, and stickynote pause 3h shuts it up without uninstalling anything.

How do I get rid of it?

stickynote stop --purge removes the background agent and the app. Deleting ~/.config/stickynote takes the settings with it. Nothing else is touched.

Do I need Xcode?

Only for the fancy parts. Without the Xcode Command Line Tools the notes still arrive; you just don't get the badge images or the settings window. The installer tells you and carries on either way.
